How to get YT Music headers (1 minute setup)
  1. Buka music.youtube.com di browser dan pastikan login.
  2. Buka Developer Tools (tekan F12) lalu klik tab Network.
  3. Klik sembarang lagu atau playlist di YouTube Music agar ada request jaringan.
  4. Cari request bernama browse atau search di daftar network.
  5. Klik kanan request tersebut → Copy → Copy Request Headers.
  6. Paste ke dalam kotak teks di atas lalu klik Connect YouTube Music.
